# 2026-06-29

## 修复 inquirer v14 兼容性问题

- **问题**：`inquirer` 从 v13 升级到 v14 后，v14 为纯 ESM 包，`scripts/release.js`（CommonJS）中的 `require('inquirer')` 会报错。
- **修复**：将 `scripts/release.js` 重命名为 `scripts/release.mjs`，改用 ESM `import` 语法（`import { createPromptModule } from 'inquirer'`），`fs.readFileSync` 路径改用 `new URL('../package.json', import.meta.url)`。
- **package.json**：`scripts.release` 命令更新为 `node scripts/release.mjs`。
- **提交**：`fix: migrate release script to ESM for inquirer v14 compatibility`

## 升级为 CJS/ESM 双格式包

- **问题根因**：项目 `"type": "commonjs"`，ESM 产物用 `.js` 扩展名时 Node.js 会误当 CJS 解析。
- **package.json**：补全 `exports` 条件导出（`import`/`require`/`browser` 各含 `types` 和 `default`）；`module` 字段改指 `.mjs`；新增 `browser` 字段；`types` 改指 `dist/index.d.ts`；新增 `sideEffects: false`。
- **rollup.config.mjs**：ESM 产物改输出 `.mjs` / `.min.mjs`；新增 `copyDts` 插件，构建完成后自动将 `src/index.d.ts` 复制为 `dist/index.d.ts`（ESM）和 `dist/index.d.cts`（CJS）；非压缩产物加 sourcemap；提取 `sharedPlugins` 复用。
- **src/index.d.ts**：从旧式 `declare module 'uuid-nanoid'` 改为标准 ambient 风格。
- **提交**：`feat: upgrade to dual CJS/ESM package with proper exports field`

## 改造为 type=module，构建前清空 dist，统一产物扩展名

- `package.json`：`"type"` 改为 `"module"`；ESM 产物回退为 `.esm.js`（项目为 ESM 后 `.js` 即被视为 ESM）；UMD 产物改为 `.umd.cjs`（确保 `require()` 在 ESM 包中仍可加载）。
- `rollup.config.mjs`：新增 `cleanDist` 插件（`buildStart` 清空 dist）；统一产物命名：`.cjs`/`.cjs.min.js`、`.esm.js`/`.esm.min.js`、`.umd.cjs`/`.umd.min.cjs`。
- `scripts/release.mjs`：删除无用的 `createRequire` import。
- **提交**：`refactor: switch to type=module, clean dist before build, unify output extensions`
